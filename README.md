# Phantom Toolkit

[![](https://img.shields.io/badge/python-3.12+-blue.svg)](https://www.python.org/downloads/)
[![](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

This is a toolkit for Elden Ring and Dark Souls III. It provides build creation and stat editing, as well as character build creation and save backup.

## Installation

### Prerequisites
1.  Download the latest release executable.
2.  **IMPORTANT**: Download the `items` folder from the release page.

### Items Folder Setup
The `items` folder **MUST** be placed in the same directory as the `Phantom Toolkit` executable.

[Download Items Release](https://github.com/2Pz/Phantom-Toolkit/releases/tag/Items)
